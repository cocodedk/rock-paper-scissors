# Rock paper scissors

A text-only web page where two computer players, 🤖 and 👾, play rock paper scissors by
themselves, one round a second, showing the latest round, the score and the last ten rounds.

Play it: https://cocodedk.github.io/rock-paper-scissors/

Run the tests with `node --test`.

Built by graph-loop's lean loop (https://github.com/cocodedk/graph-loop) from the specs in
`docs/lean/`.
